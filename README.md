# E-Commerce Sales Dashboard

## 📊 Project Overview

This project contains an interactive **E-Commerce Sales Dashboard built in Microsoft Excel**. The dashboard provides a clear overview of sales performance and helps identify key business trends and insights.

The project demonstrates my ability to use **Excel for data analysis, visualization, KPI tracking, and dashboard development**.

## 🎯 Objectives

- Analyze overall e-commerce sales performance
- Track key business KPIs
- Identify sales trends and patterns
- Understand product/category performance
- Present data in an interactive and easy-to-understand dashboard

## 🛠️ Tools & Skills Used

- **Microsoft Excel**
- Pivot Tables
- Pivot Charts
- Excel Functions
- Data Cleaning & Transformation
- KPI Analysis
- Interactive Dashboard Design
- Data Visualization

## 📈 Dashboard Features

The dashboard includes:

- Total Sales
- Key performance indicators (KPIs)
- Sales trends
- Product/category analysis
- Interactive filters and slicers
- Charts and visualizations for business insights

## 📂 Files

| File | Description |

## 🔍 Key Insights

The dashboard can be used to analyze:

- Which products/categories generate the most sales
- Changes in sales over time
- Top-performing segments
- Overall sales performance
- Areas that may require further business attention

## 🚀 How to Use


1. Open the file using **Microsoft Excel**.
2. Navigate to the dashboard sheet.
3. Use the available slicers/filters to interact with the dashboard.
4. Explore the charts and KPIs to analyze the data.
